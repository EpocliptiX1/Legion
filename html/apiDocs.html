Embed movies, TV shows, and anime on your own site through AniKino - one iframe, one URL, pulling from our Mega, KAA, Neko, RU MV, and Kino sources under the hood so you don't have to juggle providers yourself.

Introduction

The AniKino embed API will let you drop a single <iframe> into your own site and get a fully working player - no API key, no sign-up, same idea as VidSrc's embed model. Behind the scenes, AniKino resolves the best available source across our providers (Mega, KAA, Neko, RU MV, Kino) and serves whichever one is fastest/most reliable for that title.

Providers

Every embed pulls from one (or more, with automatic fallback) of these sources. Most integrators won't need to pick one manually - AniKino resolves the best option automatically - but a server parameter to force a specific provider is planned.

Mega

General-purpose fallback source, broad title coverage.

server=mega

KAA

Primary anime source - fastest resolution for most airing/finished anime.

server=kaa

Neko

Secondary anime source, used as a fallback alongside KAA.

server=neko

RU MV

Russian-dub source - used for dub coverage other providers miss.

server=rumv

Kino

Movie/TV source for non-anime content.

server=kino
